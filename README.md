# Deep Learning with PyTorch

Practical PyTorch notebooks covering classification, convolutional neural networks, and regression.

## Repository Structure

```text
Pytorch/
|-- classification/
|   |-- diabetes-risk/
|-- cnn/
|-- regression/
```

## Projects

### Classification

- **Diabetes risk prediction**: tabular binary classification with PyTorch and transfer learning/fine-tuning experiments.

### CNN

Reserved for image classification projects, including Fashion-MNIST experiments.

### Regression

Reserved for linear, house-price, and other continuous-value prediction projects.

## Getting Started

1. Create a Python environment and install PyTorch, pandas, scikit-learn, and Jupyter.
2. Open a notebook from the relevant folder.
3. Keep datasets and generated model files near the notebook when a project requires them.

Large Fashion-MNIST CSV files are intentionally excluded from Git. Download them separately before running the future CNN notebooks.
