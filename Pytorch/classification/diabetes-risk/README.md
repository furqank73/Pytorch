# Diabetes Risk Prediction

This project uses PyTorch to classify diabetes risk from tabular patient data. The notebook also includes model fine-tuning experiments.

## Files

- `diabetespytorchwithfinetuning.ipynb`: training and evaluation notebook
- `diabetes_risk.csv`: dataset
- `diabetesscaler.pkl`: feature scaler
- `diabetesprediction.pth`: saved model weights

Open the notebook from this directory so its relative data paths resolve correctly.
